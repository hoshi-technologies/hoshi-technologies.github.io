1アプリをインストールする

インストールは1分で完了し、ストアや注文が変更されることはありません。

  1. Shopify App Storeでアプリのページを開き、「インストール」をクリックします。
  2. 注文へのアクセスを許可します。アプリは請求書を作成するために注文を読み取り、注文には請求書のリンクという1つの情報だけを保存します。それ以外は何も変更しません。
  3. アプリはShopify管理画面の アプリ › Hoshi Factures で開きます。ストア名、住所、メールアドレスはすでに入力されています。
  4. 「ホーム」タブで「はじめに」のリストに沿って進めてください。3つのステップが完了すると、リストは表示されなくなります。
ヒント: 無料プラン（月 10 件の請求書）から始められ、クレジットカードは不要です。

2会社情報を入力する

これらの情報はすべての請求書に記載されます。有効な請求書に必須の情報です。

  1. 「設定」タブを開き、「会社情報」カードを表示します。
  2. 最も早い方法（フランスの会社の場合）：「自動入力」でSIRET（または会社名と市区町村）を入力し、「検索」、「使用」の順にクリックします。会社名、本社所在地、SIRET、法人形態、VAT番号が公式の登録簿から取得されます。「Shopifyの情報を使用」をクリックすることもできます。
  3. 会社名とメールアドレスを確認します。お客様からの返信はこのアドレスに届き、請求書のコピーもこのアドレスで受け取ります。
  4. 住所を複数行で入力し、郵便番号と市区町村は同じ行に入力します（例：「69002 Lyon」）。その後、国を選択します。
  5. 事業者登録番号（フランスではSIRET）とVAT番号を入力します。
  6. 付加価値税免除の小規模事業者の場合：付加価値税免除のオプションにチェックを入れます。請求書から付加価値税が表示されなくなり、法定記載事項が追加されます。
  7. 「その他の会社情報」を開き、法人形態と資本金、商業登記簿、電話番号、ウェブサイト、販売しているもの（物品、サービス、またはその両方）を入力します。
  8. 画面下部に表示されるバーの「保存」をクリックします。
ヒント: 最初の請求書を会計士にご確認いただいてください。事業に固有の記載事項をよく把握しています。
ヒント: 付加価値税が免除されている場合は、Shopifyがお客様に税金を請求していないこともご確認ください（設定 › 税金と関税）。

3請求書をカスタマイズして確認する

請求書をブランドに合ったデザインにし、最初の注文の前に仕上がりを確認しましょう。

  1. Shopifyで コンテンツ › ファイル を開き、ロゴ（PNGまたはJPEG）をアップロードして、そのリンクをコピーします。
  2. 設定 › 外観 で、「ロゴのURL」にリンクを貼り付け、メインカラーを選択します。
  3. 必要に応じて、法定記載事項とお礼のメッセージを編集します。空欄の場合は、お客様の言語に自動で翻訳されます。
  4. 「PDFをプレビュー」をクリックすると、現在の設定（未保存の設定も含む）でサンプルの請求書がダウンロードされます。
  5. 仕上がりに問題がなければ保存します。
ヒント: 設定は以降の請求書にのみ適用されます。発行済みの請求書が変わることはありません。

4請求書の送信タイミングと方法を選ぶ

既定では、注文の支払い完了時に請求書が作成され、すぐにお客様へメールで送信されます。

  1. 設定 › 仕組み で、請求書を作成するタイミングを選択します：注文の支払いが完了したとき（推奨）、または注文が確定した時点。
  2. 「お客様が請求書を受け取る方法」で、次のいずれかを選択します：PDFを添付したメール（推奨、設定不要）、注文ページに「請求書をダウンロード」ボタンを表示するメール1通のみ（コード不要：3クリックで有効化）、またはShopifyの確認メールに直接リンクを表示するメール1通のみ（初回のみコードを貼り付け）。設定画面で手順をご案内します。
  3. 「すべての請求書のコピーを自分にも送信する」にチェックを入れると、各請求書を受け取ってアーカイブを作成できます。
  4. メールをカスタマイズするには、「お客様へのメール」を開きます。件名と本文には変数 {{first_name}}、{{name}}、{{invoice_number}}、{{order}}、{{shop}} を使用できます。
ヒント: Shopifyでは、Shopify自身のメールに添付ファイルを含めることはできません。請求書は、ストアの名義で送信される別のメールで届きます。

5Shopifyの注文確認メールに請求書のリンクを追加する（任意）

お客様は、ストアからの通常の確認メールからも請求書を取得できます。

  1. 「設定」で「Shopifyの注文確認メール内のリンク」を開き、「コードをコピー」をクリックします。
  2. Shopifyで 設定 › 通知 › お客様への通知 › 注文確認 に移動し、「コードを編集」をクリックします。
  3. ボタンを表示したい場所（例：注文概要の直後）にコードを貼り付けます。
  4. 「プレビュー」をクリックして確認し、「保存」をクリックします。
ヒント: お客様が支払い前にクリックした場合は、請求書が数分後に利用可能になることを案内するページが表示されます。

6請求書を日々管理する

「ホーム」タブには、最近の請求書が送信ステータスとともに一覧表示されます。

  1. 各行には、番号、注文、お客様、日付、合計、メールのステータスが表示されます。
  2. 「送信済み」：お客様が請求書を受け取りました。「未送信」：自動送信がオフになっています。「失敗」：ステータスにカーソルを合わせると原因が表示されます。
  3. 「PDF」をクリックすると請求書をダウンロードでき、「再送信」をクリックするとお客様に再度送信できます。
  4. Factur-Xバッジは、請求書に電子請求書用のデータも含まれていることを示します。
ヒント: 送信に失敗した場合は、Shopifyの注文でお客様のメールアドレスを確認し、迷惑メールフォルダを確認するようお客様にご依頼ください。

7番号と言語

法律の定めに従い、番号は欠番なく連続し、お客様はそれぞれご自身の言語で請求書を受け取ります。

  1. 設定 › 番号と言語 で、番号のプレフィックスを選択します（既定は「F-」、つまり F-2026-00001）。
  2. すでに別のツールで請求書を発行している場合は、次の番号を指定します。番号は増やすことはできますが、減らすことはできません。
  3. 請求書の言語を選択します：お客様の言語（フランス語、英語、ドイツ語、スペイン語、イタリア語、オランダ語、ポルトガル語 (ブラジル)、チェコ語、デンマーク語、フィンランド語、ノルウェー語(ブークモール)、ポーランド語、ポルトガル語 (イベリア半島)、スウェーデン語、トルコ語、マレー語）または固定の言語。
  4. 「お客様の言語」を選択した場合は、お客様の言語が利用できないときに使用する代替言語も選択します。

8Factur-X：電子請求書

Factur-Xでは、PDFに請求書データも含まれ、会計ソフトや電子請求書プラットフォームで読み取ることができます。フランスでは2026～2027年から、企業間取引で電子請求書が義務化されます。

  1. 設定 › Factur-X を開きます。このオプションは既定でオンになっています。
  2. 「Factur-Xは一時停止中です」と表示された場合は、不足している情報（多くの場合、住所、国、VAT番号）を入力して保存します。
  3. インジケーターが ✓ に変わると、以降の請求書はすべてFactur-X形式になります。お客様にとっての変化はありません。
ヒント: 会計士は、これらの請求書を会計ソフトに直接取り込むことができます。

9プランを管理する

無料プラン：月 10 件の請求書。エッセンシャル：月額 $7.90 で 200 件の請求書。無制限：月額 $12.90。有料プランには 7 日間の無料体験があります。

  1. 「プラン」タブ（および「ホーム」）に、今月使用した請求書の件数が表示されます。カウンターは毎月1日にリセットされます。
  2. プランを変更するには、「選択」をクリックしてShopifyのページで承認します。料金はShopifyのご利用料金に加算されます。
  3. 上限に達すると、新しい注文は保留となり、メールでお知らせします。アップグレード後に、「ホーム」で「請求書を作成する」をクリックしてください。
  4. 無料プランに戻すには、「解約」をクリックします。

10おすすめの使い方

安心して経理を行うための、いくつかの習慣をご紹介します。

  1. 設定後にテスト注文を行い（Shopify Paymentsのテストモードを使用）、受け取った請求書を確認します。
  2. 請求書は10年間保存してください。メールのコピーを保管するか、毎月ダウンロードします。請求書はアンインストールの48時間後にアプリから削除されます。
  3. 発行済みの請求書は変更できません。誤りや返金があった場合は、会計ツールでクレジットノートを発行してください。
  4. ご不明な点がある場合は、「ヘルプ」タブのFAQをご覧ください。
